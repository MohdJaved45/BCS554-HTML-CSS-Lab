## 🚀 Completed Labs Summary

### 🔹 Lab 01: Starting a Git Repository
- Configured local Git repository (`git init`) and set user parameters (`git config --local`).
- Created initial commits tracking core HTML structure and incremental page revisions.

### 🔹 Lab 02: Pushing and Cloning a Repository
- Configured a local `--bare` remote repository (`html-remote`) and established origin tracking.
- Successfully pushed commits across branches and verified cloning operations (`git clone`).

### 🔹 Lab 03: Your First HTML Page
- Built foundational HTML pages (`first.html`, `headings.html`, `text-format.html`).
- Applied standard heading hierarchies (`<h1>`–`<h3>`) and text formatting elements (`<strong>`, `<em>`, `<br>`).

### 🔹 Lab 04: Divs, Attributes and a Small Fix
- Organized content layouts using container `<div>` tags paired with functional classes.
- Implemented custom dataset attributes (`data-*`) and debugged structural HTML errors.

### 🔹 Lab 05: Links and Images
- Implemented bidirectional page navigation using anchor tags (`<a>`).
- Embedded localized images with relative paths, explicit dimension bounds, and accessibility `alt` text.

### 🔹 Lab 06: Types of HTML Lists
- Constructed unordered lists (`<ul>`), nested ordered lists (`<ol>`), and key-value description lists (`<dl>`, `<dt>`, `<dd>`).
