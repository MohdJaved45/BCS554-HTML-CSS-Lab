## 🎯 Aim

## 📄 Tasks Completed

### Task 1: Basic Structure (`first.html`)
Created a baseline HTML document containing document type declaration, metadata structure, browser title **"My First Page"**, and an `<h1>` heading.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Page</title>
</head>
<body>
    <h1>Hello, I am Asha</h1>
</body>
</html>
```

---

### Task 2: Heading Hierarchy (`headings.html`)
Demonstrated proper heading hierarchy using `<h1>`, `<h2>`, `<h3>` tags alongside a descriptive paragraph block.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Headings Practice</title>
</head>
<body>
    <h1>Main Heading (H1)</h1>
    <h2>Sub Heading (H2)</h2>
    <h3>Section Heading (H3)</h3>
    <p>This is a paragraph under the headings demonstrating different text levels in HTML.</p>
</body>
</html>
```

---

### Task 3: Text Formatting Elements (`text-format.html`)
Utilized `<strong>` for structural emphasis (bolding), `<em>` for semantic stress (italics), and `<br>` for manual line breaking inside paragraph units.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Text Formatting</title>
</head>
<body>
    <p>This is a paragraph with a <strong>strong bold</strong> word inside it.</p>
    <p>This second paragraph has an <em>emphasized italic</em> word and<br>includes a line break.</p>
</body>
</html>
```
